Reports common mistakes in the structure of an OPENRNDR program:
  • extend { } inside another extend { }: the inner block runs every frame and adds a new extension each time.
  • configure { } inside program { }: the window has already been created, so the configuration has no effect. It belongs in application { }, before program { }.
  • Loading images, fonts or videos, or creating other GPU resources (colorBuffer, renderTarget, …), inside application { } but outside program { }: there is no graphics context yet, so the program fails at startup.
  • Loading images, fonts, videos or SVG files inside extend { }: they are loaded again every frame. Load them once in program { }, before extend { }.

Example:

fun main() = application {
    val image = loadImage("data/images/cheeta.jpg") // needs program { }

    program {
        configure { width = 720 }                   // belongs in application { }
        extend {
            extend { drawer.image(image) }          // adds an extension every frame
            val font = loadFont("data/fonts/default.otf", 24.0) // loaded every frame
        }
    }
}
